# Classroom Assistant — What's Included

**Branch:** `testing/full-platform-integration-2026-07`  
**Phase 22:** Paused  
**Parsing:** Local deterministic only (no live AI)

## Product scope

- Group meals, activities, naps, diaper changes, potty logs, medication logs, attendance, and daily summaries from natural language.
- Automatically recognizes checked-in children and understands when part of a note only applies to one child.
- Converts short notes into professional parent messages, incident reports, behavior reports, observations, developmental notes, daily reports, and documentation.
- Helps providers find the right words when communicating difficult situations with families.
- Preview everything before saving so providers stay in control.
- Admin Assistant for lesson plans and curriculum. Paste content once and automatically organize it into lesson plans, curriculum, categories, age groups, learning domains, objectives, materials, and more before review.
- Smart suggestions throughout the Classroom Assistant surface to save time and reduce repetitive typing.
- Works with offline mode. If internet is unavailable, continue working as normal. Everything syncs automatically once a connection is restored.

## Safety

- Fake/testing data only
- Preview / confirm before apply
- Medication logs always require extra review
- No live AI, Stripe, outbound email, SMS, or push
- Production host rejects Classroom Assistant routes
