## Guardrails for rebuild

- No activity image changes  
- No cover changes  
- No lesson body rewrites unless a printable name reference must match  
- Replace/unlink old resources; new titles **without** “(Draft)”  
- Leave resource `status: draft` / enrichment unpublished for owner Publish  
- Prefer 2–3 strong resources per lesson over many filler signs
