Guardrails

Do / Don’t

Do

  • Use lavender as primary chrome
  • Keep large headers and whitespace
  • One primary button per region
  • Soft washes for status chips
  • Reuse tokens — no one-off hex

Don’t

  • Ship all-blue corporate SaaS UI
  • Rainbow every card a new color
  • Heavy gradients as the main look
  • Button piles and crowded sections
  • Parallel assignment systems
