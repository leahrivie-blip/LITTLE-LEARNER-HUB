# Little Learner Hub — Lesson Cover Standard

**Status:** Locked for curriculum visual review (2026-08-08)  
**Scope:** All published lesson-plan covers across age groups  
**Rule:** Prefer UI/template title overlay; do not bake AI typography into artwork when architecture supports overlay.

## Style

Warm, polished children’s educational **cartoon / modern preschool picture-book** illustration.

Think:
- Friendly classroom-resource artwork
- Soft, playful shapes
- Cheerful but not overstimulating
- Clean composition
- Professional enough for a paid curriculum product

### Must look like
- Picture-book watercolor or soft digital painting (matching existing KEEP covers such as `farm-animals.jpg`, `bugs-butterflies.jpg`, `construction-crew.jpg`)

### Must NOT look like
- Photographs or photorealistic AI art
- 3D renders
- Random Canva templates
- Clip-art collages / flat geometric SVG placeholders
- Hyper-realistic children
- Anime
- Overly childish “baby clip-art”
- Generic corporate illustrations

## Characters

- When children or teachers appear, they must be clearly **illustrated/cartoon** characters
- Natural proportions and expressions; natural diversity across the catalog
- No malformed hands, faces, limbs, eyes, or background people

## Age matching (required)

| Age band | Visual expectation |
| --- | --- |
| Infant | Babies/caregivers, tummy-time, sensory materials, soft toys — **no preschool-looking kids** |
| Toddler | Young toddlers in simple hands-on / play-based exploration |
| Preschool | Preschool-age children in pretend play, STEM, investigation, building, art, nature |
| School-age | Older children with age-appropriate activity visuals |

Do not put preschool children on infant lessons or elementary children on toddler lessons.

## Theme accuracy

The illustration must communicate the lesson theme **before the title is read** (Farm → farm; Construction → building play; Space → rockets/stars; Apple Orchard → orchard/apples; Pumpkin Patch → pumpkins/fall; Five Senses → sensory exploration; Music & Movement → instruments/movement).

## Composition

- Keep important artwork away from extreme edges (responsive card crops)
- Must work on: desktop cards, mobile cards, lesson viewer, Teaching Kit, Admin Preview as User, print/PDF where applicable
- Leave quiet upper area for UI title when possible

## Text

- Use the lesson’s **exact canonical title** in UI overlay
- Do not invent additional text in the image
- No random letters, signs, labels, or fake writing inside illustrations

## Branding

- Subtle, consistent Little Learner Hub curriculum feel
- Covers should read as one library, not different products/companies

## Quality gate (reject if any fail)

- [ ] Cartoon/illustrated style
- [ ] Correct lesson + age representation
- [ ] Theme immediately understandable
- [ ] No AI artifacts / malformed people / gibberish text / spelling errors
- [ ] No accidental logos/branding
- [ ] Good mobile + desktop crop
- [ ] Clear title treatment (prefer UI)
- [ ] Consistent with LLH library
- [ ] Appropriate for paid professional curriculum
- [ ] File loads; durable media URL/storage
- [ ] Lesson otherwise unchanged (content, IDs, publish state, TK flags)
