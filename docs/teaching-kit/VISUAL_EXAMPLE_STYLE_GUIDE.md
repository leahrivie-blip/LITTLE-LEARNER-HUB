# Visual Example Style Guide

Teaching Kit example images should never look obviously AI-generated. Everything should look **achievable in a real childcare classroom**.

---

## Preferred style

- Simple classroom setup (table tray, rug corner, shelf)
- Teacher-guide style photos or scans
- Educational illustrations and diagrams
- Paper craft / printable examples
- Soft cartoon illustrations when photos are unavailable
- Natural lighting, ordinary materials, real mess tolerance

## Avoid

- Glossy fake classrooms
- Unrealistic or “stock” children
- AI artifacts (extra fingers, warped text, impossible props)
- Fancy lifestyle stock-photo styling
- Heavy filters, glow, or hyper-saturated product shots

---

## Shot types

| Type | Purpose |
| --- | --- |
| Setup example | Materials laid out before children arrive |
| Finished / in-use example | What success looks like mid-activity or at the end |
| Printable preview | Ink-friendly card / sheet preview |
| Diagram | Simple steps or station layout |

---

## Admin checklist before approve

1. Could a provider recreate this with ordinary classroom supplies?
2. Would a parent or director recognize this as a real room?
3. Is text on printables readable when printed B&W?
4. Does the image help teach, or is it decoration only?

If any answer is “no,” revise or replace before publishing enrichment.
