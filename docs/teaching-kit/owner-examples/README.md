# Owner lesson examples & picture ideas

Permanent drop folder for materials Leah supplies when upgrading Teaching Kits.

## How agents must use this folder

1. When the owner pastes or attaches lesson plan examples, picture ideas, printable concepts, or activity notes, **save them here** (do not leave them only in chat).
2. Follow them **together with** the [Teaching Kit Master Specification](../TEACHING_KIT_MASTER_SPECIFICATION.md).
3. Treat owner files as design intent for that lesson’s brief and draft — not as permission to copy third-party products.
4. Inspiration from Pinterest/teacher sites may inform ideas only; never copy images, wording, layouts, or products.

## Suggested layout

```
owner-examples/
  README.md
  <lesson-slug>/
    NOTES.md              # transcribed / summarized owner direction
    lesson-plan-example.* # owner-provided plan samples
    picture-ideas/        # sketches, references, image briefs (no copyrighted scrapes)
```

Use a clear lesson slug (e.g. `amazing-apples-toddler`, `all-about-me-preschool`).
