# Lesson briefs

Required **before** building or revising a Teaching Kit upgrade.

Each brief must satisfy §2 of the [Teaching Kit Master Specification](../TEACHING_KIT_MASTER_SPECIFICATION.md).

## File naming

```
docs/teaching-kit/lesson-briefs/<lesson-slug>-brief.md
```

Examples:

- `amazing-apples-toddler-brief.md`
- `all-about-me-preschool-brief.md`

## Minimum sections

Copy and fill:

```markdown
# Lesson brief — <Title> (<Age group>)

## Weekly purpose
## Learning objectives
## Monday–Friday focuses
## Existing activity decisions (keep / improve / replace / remove + reason)
## Developmental balance
## Printable plan (every page + classroom purpose)
## Image plan (only justified needs)
## Songs (original or public-domain + motions + teaching directions)
## Books (verified + weekday + questions + vocab + substitutes + no-book alternative)
## Teacher preparation & classroom supports
## Family connections
## Open questions for owner
```

Do not start draft build work until the brief exists for that lesson (and, when the owner has asked for brief-first review, until they approve it).
