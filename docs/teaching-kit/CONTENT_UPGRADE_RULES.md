# Complete Teaching Kit Content Upgrade Rules

**Status:** Canonical — active for all lesson upgrades  
**Audience:** Curriculum authors, AI assist, Cursor agents, Quality Review  
**Framework:** Teaching Kit is complete and live. Upgrade content into the existing structure only.

---

## Non-negotiable rules

1. **Do NOT change the Teaching Kit layout.** Do not redesign, move, rename, or skip binder sections.
2. **Do NOT remove existing functionality.**
3. **Do NOT generate or replace cover images.**
4. **Do NOT generate activity images.**
5. **Do NOT generate printables.**
6. **Do NOT publish placeholder AI images.**
7. **Leave image placeholders or image prompt fields** for the owner to complete later.
8. **Preserve all existing lesson plans** and upgrade them **non-destructively**.
9. **Do not copy copyrighted material** (books, song lyrics, printables, or proprietary activity plans).

If a rule conflicts with an older doc or gate, **this file wins** for content upgrade work.

---

## Content standards

Every Teaching Kit should feel like a **premium digital teacher binder** that saves providers hours of planning.

- Never add filler.
- If something is weak, improve it.
- If something is repetitive, replace it.
- Every activity must have a clear educational purpose.
- Create **original** activities inspired by current early childhood education best practices (invitations to play, loose parts, process art, sensory exploration, child-led learning, seasonal/nature themes, STEM, dramatic play). Do **not** chase short-lived social trends.

### Subscriber lens (required before marking complete)

Before upgrading any lesson, review the entire Teaching Kit as if you were a childcare provider paying **$19.99/month**. If any section feels incomplete, repetitive, confusing, or not worth the subscription price, improve it before marking the lesson complete. Every Teaching Kit should feel like a polished, premium product that saves teachers hours of work.

---

## Developmentally appropriate

Before saving any lesson, verify every activity fits the intended age group.

| Age | Must not include |
| --- | --- |
| Infants | Preschool / formal school tasks |
| Toddlers | Kindergarten expectations, worksheets, fine pencil work |
| Preschool | Worksheet-heavy “schoolish” packs; keep K-readiness play-based |

Always match:

- attention span  
- safety  
- language level  
- fine motor expectations  
- gross motor expectations  
- cognitive expectations  
- sensory expectations  
- social-emotional expectations  

If an activity is not age appropriate, **replace it**.

## Complete Teaching Kit sections

Every upgraded lesson must include the **existing** Teaching Kit structure exactly as designed, including:

- Overview  
- Weekly Plan  
- Learning Objectives  
- Materials List  
- Teacher Preparation  
- Daily Activities  
- Circle Time  
- Books  
- Songs  
- Song Lyrics *(only original or public-domain songs in full; otherwise title + short description — never copyrighted lyrics)*  
- STEM  
- Sensory  
- Fine Motor  
- Gross Motor  
- Literacy  
- Math  
- Art  
- Dramatic Play  
- Outdoor Play  
- Small Group  
- Teacher Tips  
- Observation Opportunities  
- Family Connection  
- Teacher Toolkit  
- Printables section **(placeholders only)**  
- Images section **(placeholders only)**  

Do not skip sections unless they truly do not apply to that age/theme — and document why if omitted.

---

## Activity quality

- Replace outdated or weak activities with stronger ones.
- Activities should feel current, engaging, and classroom-realistic.
- Prefer invitations to play, process over product, and clear teacher directions.
- No duplicate activities within the same kit.

---

## Books

Recommend high-quality children’s books. **Never reproduce copyrighted book text.**

Provide only:

- Title  
- Author  
- Brief description / why it fits  
- Discussion ideas (before / during / after as supported by the binder fields)

---

## Songs

Use:

- Original songs  
- Public-domain songs  
- Traditional nursery rhymes  

For copyrighted songs:

- Include **title** and when to use it  
- Motions / teaching directions as appropriate  
- **Do NOT include copyrighted lyrics**

---

## Printables (owner-created later)

**Do not create printable files or generated packs during content upgrade.**

Instead include placeholders such as:

**Printable Needed:**

- tracing sheet  
- matching game  
- vocabulary cards  
- sequencing cards  
- dramatic play signs  
- parent handout  

Store these as printable ideas / notes in the existing Printables section. Leave final artwork and files for manual creation.

---

## Images (owner-created later)

**Do not generate images. Do not publish AI placeholder artwork.**

Instead include notes like:

**Image Needed:**  
“Children exploring a farm sensory bin.”

or

“Teacher setting up dramatic play veterinarian clinic.”

or

“Finished invitation to play example.”

Use existing image-brief / prompt fields. The owner creates final artwork later.

- Formatting  
- Writing style  
- Quality  
- Sections  
- Tone  
- Difficulty

## Teaching Kit cover standards

Every Teaching Kit must have a professional, consistent cover.

Review every existing cover against these standards:

- Artwork is bright, warm, colorful, and welcoming.
- Consistent **cartoon / illustrated** style across the curriculum.
- Do **not** mix realistic photos, watercolor, clip art, 3D renders, or different illustration styles.
- Artwork clearly matches the lesson theme and age group.
- Cover immediately communicates what the lesson is about.
- Characters represent young children in classroom, home, or outdoor learning environments when appropriate.
- Backgrounds support the theme without clutter.
- Visual style is clean, modern, and premium.
- Every cover feels like it belongs in the same curriculum collection.
- Avoid generic AI-looking artwork, distorted faces, incorrect hands, unreadable text, or inconsistent proportions.
- Developmentally appropriate and visually engaging for early childhood educators.
- Title and artwork always match the lesson content.

### If a cover does not meet these standards

1. **Do not** generate or permanently replace the artwork.
2. **Flag it for owner review.**
3. Create a **detailed image prompt** describing the ideal cover that matches the lesson theme and the established cartoon illustration style.
4. Leave final artwork for **manual approval** before publishing.

## Quality review checklist (before saving)

Verify every lesson:

- [ ] Age appropriate  
- [ ] No duplicate activities  
- [ ] Complete Teaching Kit sections  
- [ ] Clear teacher instructions  
- [ ] Materials included  
- [ ] Teacher preparation included  
- [ ] Learning objectives included  
- [ ] Observation opportunities included  
- [ ] Family connection included  
- [ ] Books included (title, author, description, discussion — no book text)  
- [ ] Songs included (lyrics handled correctly)  
- [ ] Teacher toolkit completed  
- [ ] Printables noted as placeholders (“Printable Needed”)  
- [ ] Image placeholders / prompts added (“Image Needed”)  
- [ ] Cover reviewed (or flagged with owner prompt — never auto-replaced)  
- [ ] Premium quality under the $19.99/month subscriber lens  

If any educational section is missing or weak, improve it before saving.

## Agent / tooling policy

| Action | Allowed during content upgrade? |
| --- | --- |
| Improve text, activities, objectives, toolkit, family, observations | Yes |
| Add book/song metadata (no copyrighted lyrics/book text) | Yes |
| Add printable **needed** notes / ideas | Yes |
| Add image **needed** briefs / prompts | Yes |
| Flag weak covers + write owner cover prompts | Yes |
| Generate / upload / replace cover or activity images | **No** |
| Generate printable PDFs or packs | **No** |
| Publish AI placeholder images | **No** |
| Redesign binder layout / rename sections | **No** |
| Destructive rewrite that drops legacy content | **No** |

Quality Review treats thorough **printables ideas** and **image briefs** as satisfying the content-upgrade media slots. Real files remain **owner media pending** and are not hard blockers for educational content completion.
