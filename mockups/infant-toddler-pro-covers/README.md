# Infant / Toddler Pro covers — style APPROVED

**Status:** Leah approved the round-2 bold cartoon / picture-book style on 2026-07-21.

Use this style for new weekly lesson covers and monthly curriculum covers:
- 16:9
- Bold flat color, thick outlines, sticker/picture-book cartoon look
- Childcare-friendly, no text baked into the art
- Not soft photorealistic / airbrushed AI realism
